## 踩到的最大一个坑：ccr 必须锁 2.0.0

先装了最新版 3.1.3，反编译 dist 逐个核对，确认它对这套方案是硬伤：

- 3.x 会把模型 ID 里 `/` 前面那截当成**自己的供应商标识**解析，`anthropic` / `openai` / `google` 是一等公民，
  于是 `anthropic/claude-opus-5.5` 和 `claude-sonnet-5.5` 报 `conflicts with target provider` 且前缀被剥掉，
  **Opus / Sonnet 根本调不通**；`moonshotai/` 和 `deepseek/` 前缀它不认识，反而正常。
- 3.x 配置改存 SQLite，`config.json` 只在库不存在时导入一次，导完当场删除 —— 改 JSON 不生效。
- 3.x 会静默丢弃 `Router.default / background / think / longContext`。
- 3.x 还会改写 `~/.claude/settings.json` 做 profile 接管（已还原，备份 `settings.json.v3-takeover.bak`）。

结论：锁 2.0.0。升级前必须先确认这个坑还在不在。

## 路由脚本的两个刻意设计

- **只扫 `role==="user"` 的消息**。Claude Code 的 system prompt 里塞满 `api` / `build` / `日志`，
  全量扫会大量误判 —— 自测里专门加了 `o)` 用例守这条。
- **显式指定要搭配动词**（用 / 切成 / 换成 / 指定…），否则闲聊里提到 opus 也会误触发。
