# 2026-10-11

## Set up the Claude Code multi-model routing environment

Implemented and verified the "6 engineering responsibilities -> 4 OpenRouter models" dispatch scheme
on this machine.

- Installed `claude-code-router`, wrote `config.json` + `custom-router.js` for keyword-based dispatch.
- The key lives in the `OPENROUTER_API_KEY` environment variable; the config file only holds the
  `$OPENROUTER_API_KEY` placeholder, so no plaintext secret ever lands on disk.

## The biggest trap: ccr must be pinned to 2.0.0

Installed the latest 3.1.3 first; decompiling its dist confirmed it is a hard blocker for this setup:

- 3.x parses the segment before `/` in a model ID as **its own provider identifier**.
  `anthropic` / `openai` / `google` are first-class citizens, so `anthropic/claude-opus-5.5` and
  `claude-sonnet-5.5` fail with `conflicts with target provider` and get their prefix stripped —
  **Opus and Sonnet are simply unreachable**. The `moonshotai/` and `deepseek/` prefixes are unknown to it,
  so those pass through fine.
- 3.x moved config into SQLite; `config.json` is imported once only when the DB does not exist and then
  deleted immediately — editing the JSON has no effect.
- 3.x silently drops `Router.default / background / think / longContext`.
- 3.x also rewrote `~/.claude/settings.json` to take over profiles (restored; backup at
  `settings.json.v3-takeover.bak`).

Conclusion: pin 2.0.0. Verify this bug still exists before any upgrade.

## Two deliberate design choices in the router script

- **Scan only `role==="user"` messages.** Claude Code's system prompt is full of `api` / `build` / `log`;
  scanning everything causes many false hits. Case `o)` in the tests guards this.
- **Explicit overrides must pair with a verb** ("use / switch to / change to ..."), otherwise casually
  mentioning opus triggers a switch.

## Verification

- Spun up a local echo server impersonating upstream and captured the `Authorization` header and the
  `model` field it received — this verified "key injection + routing + protocol translation" in one pass
  without a real key. All 5 cases hit the expected model.
- With a real key against OpenRouter, the `model` field in responses was correct 5/5:
  Opus 5.5 / Sonnet 5.5 / Kimi K3 / Kimi K3 / DeepSeek V4 Flash.
- Wrote 18 self-test cases (priority crossovers, system-noise isolation, explicit overrides, robustness);
  all green.
